Exotic Charting Styles

Heikin-Ashi, Renko, and Point & Figure — advanced types designed to filter noise and reveal the true trend.

Chart Type 1

Heikin-Ashi

Modifies the standard candlestick by averaging OHLC values. Smooths out price action and makes trends clearer.

Formula: HA Close = (O+H+L+C)/4  |  HA Open = (Prev HA O + Prev HA C)/2
  • Consecutive green candles with no lower wicks = strong uptrend
  • Consecutive red candles with no upper wicks = strong downtrend
  • Small body with wicks on both sides = possible reversal
Chart Type 2

Renko Charts

Ignores TIME completely. A new brick is drawn only when price moves by a preset amount. Eliminates all time-based noise.

Key Insight: During a sideways market, Renko draws nothing. You only see meaningful moves.
Chart Type 3

Point & Figure

Uses X's (rising) and O's (falling). Time is ignored — only price movement matters. Dates back to the 1800s.

How to Read: A new X is added when price rises by the box size. A new O when it falls. A new column starts on reversal.
